# میو‌سندر — اجرای ۲۴ ساعته رایگان با GitHub Actions

این راهنما برای مواقعیه که می‌خوای «میو» حتی وقتی لپ‌تاپ خاموشه هم هر ۵ دقیقه
به گروه‌هات بره. همه‌چیز روی سرورهای رایگان گیت‌هاب اجرا می‌شه.

## فایل‌های لازم

| فایل | توضیح |
|---|---|
| `send.py` | اسکریپت ارسال — متن رو از `schedule.json` می‌خونه و به گروه‌ها می‌فرسته |
| `schedule.json` | متن پیام و فاصله ارسال |
| `.github/workflows/telegram-schedule.yml` | اجرا: توسط cron-job.org هر ۵ دقیقه دقیقاً سر وقت اجرا می‌شه |

## مراحل راه‌اندازی (۵ دقیقه)

### ۱) ساخت ریپازیتوری Public
- توی [github.com](https://github.com) یه ریپازیتوری **Public** بساز
  (Public بودن مهمه چون اجرای نامحدود و رایگان فقط برای ریپازیتوری‌های Public هست).

### ۲) آپلود فایل‌ها
- سه مورد بالا (`send.py`، `schedule.json`، پوشه `.github/workflows/`) رو آپلود کن:
  - از دکمه «Add file → Upload files» یا با `git push`
- ساده‌ترین راه: این پوشه رو کپی کن و خودش رو به‌عنوان ریپازیتوری جدید push کن:
  ```
  git init
  git add send.py schedule.json .github
  git commit -m "Meow Sender"
  git remote add origin https://github.com/UserName/RepoName.git
  git push -u origin main
  ```

### ۳) ساخت دو Secret
- از تب **Settings → Secrets and variables → Actions** دو تا Secret بساز:
  - `TELEGRAM_SESSION` = همون چیزی که دکمه «آماده‌سازی برای گیت‌هاب» داخل میو‌سندر کپی می‌کنه
    (یه رشته کوتاه ~۳۵۰ کاراکتری که با عدد ۱ شروع می‌شه — سشن اکانتت به صورت
    StringSession؛ بدونش کاری نمی‌شه کرد)
  - `TELEGRAM_CHAT_ID` = آیدی گروه‌ها، با ویرگول جدا (مثلاً `-1003713917910,-1003870033750`)
    — داخل میو‌سندر بعد از انتخاب گروه، خودش آیدی رو نشونت می‌ده.
    چند گروه = چند آیدی که با `,` جدا می‌شن.

### ۴) اجرا
- از تب **Actions** دکمه **Run workflow** رو بزن — چند ثانیه بعد پیام باید بره.
- بعد از اون، برای ارسال **دقیقاً هر ۵ دقیقه**، راهنمای [SETUP_CRONJOB.md](SETUP_CRONJOB.md) رو دنبال کن
  (یه سرویس رایگان خارجی که هر ۵ دقیقه به گیت‌هاب می‌گه بفرست — چون کرون خودِ گیت‌هاب گاهی تا ۱ ساعت دیر اجرا می‌شه).
- نتیجه هر اجرا از همون تب Actions قابل مشاهده‌ست (لاگ زنده).

## تغییرات

- **عوض کردن متن پیام**: `schedule.json` رو ویرایش کن و push کن.
- **عوض کردن فاصله**: توی cron-job.org مقدار کرون رو عوض کن (مثلاً `*/5 * * * *` = هر ۵ دقیقه، `*/30 * * * *` = هر ۳۰ دقیقه).
- **گروه بیشتر**: توی Secret به نام `TELEGRAM_CHAT_ID` آیدی گروه جدید رو با ویرگول اضافه کن.

## نکته مهم: فقط یکی در یک زمان

همون سشن تلگرام رو نمی‌شه هم‌زمان از دو جا استفاده کرد (تلگرام اتصال دوم رو
می‌سوزونه و اولی رو باطل می‌کنه). پس:

- وقتی گیت‌هاب داره می‌فرسته، برنامه میو‌سندر روی لپ‌تاپ **بسته** باشه.
- اگه برنامه بازه، ارسال از گیت‌هاب و برنامه باهم تداخل پیدا می‌کنن و سشن باطل می‌شه
  (باید دوباره کپی کنی).
- ایده‌اش همینه: گیت‌هاب برای وقتیه که لپ‌تاپت خاموشه؛ وقتی لپ‌تاپ روشنه از
  برنامه خودش استفاده کن (و یا کرون گیت‌هاب رو غیرفعال کن).

## نکته امنیتی

سشن اکانت تلگرامت معادل دسترسی کامل به اکانته — فقط توی ریپازیتوری شخصی خودت
بذار و `TELEGRAM_SESSION` رو با هیچ‌کس به اشتراک نذار.
